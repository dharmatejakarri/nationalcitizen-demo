# NationalCitizen - AP Showcase Demo

> **One Platform. One Tap. Everything You Need.**

A showcase website demonstrating the NationalCitizen platform vision for Andhra Pradesh - a unified, AI-powered government services platform that connects every citizen to 600+ schemes from birth to 70+ years.

## 🚀 Live Demo

**[View Live Demo →](https://YOUR_USERNAME.github.io/nationalcitizen-demo/)**

## 📱 Pages

| Page | Description |
|------|-------------|
| **Landing** | Investor showcase with problem, solution, life stages, impact, and roadmap |
| **Dashboard** | Citizen MVP demo with scheme discovery, applications, civic score |
| **Schemes** | Scheme discovery with search, filters, and application modal |

## 🏃 Run Locally

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/nationalcitizen-demo.git

# Navigate to folder
cd nationalcitizen-demo

# Start local server (requires Node.js)
npx http-server . -p 3000 -o

# Or simply open index.html in browser
```
